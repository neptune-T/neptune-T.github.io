authors: Tianshan Zhang, Zeyu Zhang, Hao Tang
summary: DragMesh targets drag-to-move 3D interaction. Given an object and a single user drag, it decouples kinematic reasoning from motion generation. The model first infers how the part should move — whether it rotates or slides, and about which axis — then a dual-quaternion-based generative model synthesizes the full motion, which transfers to both meshes and 3D Gaussian Splatting. The result is real-time, physically valid articulation of 3D objects with reasonable generalization.
