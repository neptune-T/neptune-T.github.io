accepted: 2026-10-01
venue: IJCV 2026
authors: Tianshan Zhang, Zeyu Zhang, Hao Tang
summary: DragMesh lets a user articulate a 3D object with a single drag. It separates kinematic reasoning from motion generation. The model first infers the joint type and axis implied by the drag, then a dual-quaternion generative model produces the motion, which can be applied to meshes or 3D Gaussian Splatting. It runs in real time, keeps the articulation physically valid, and shows some generalization to new objects.
